# 📡 SignalR en .NET --- Cours avancé complet

------------------------------------------------------------------------

# 🔹 1. Introduction

SignalR est une bibliothèque ASP.NET Core permettant de faire de la
communication **temps réel** entre un serveur et des clients (web,
mobile, desktop).

Contrairement à une API REST classique : - REST = requête client →
serveur - SignalR = communication bidirectionnelle (push serveur →
client)

------------------------------------------------------------------------

# 🔹 2. Cas d'usage avancés

-   Chat temps réel (Slack, Teams)
-   Notifications temps réel
-   Trading / données financières live
-   Monitoring IoT
-   Jeux multijoueurs
-   Collaboration temps réel (Google Docs-like)

# 🔹 5. Création d'un Hub

``` csharp
using Microsoft.AspNetCore.SignalR;

public class ChatHub : Hub
{
    public async Task SendMessage(string user, string message)
    {
        await Clients.All.SendAsync("ReceiveMessage", user, message);
    }
}
```

------------------------------------------------------------------------

# 🔹 6. Configuration ASP.NET Core

``` csharp
var builder = WebApplication.CreateBuilder(args);

builder.Services.AddSignalR();

var app = builder.Build();

app.MapHub<ChatHub>("/chatHub");

app.Run();
```

------------------------------------------------------------------------

# 🔹 7. Client JavaScript

``` javascript
import * as signalR from "@microsoft/signalr";

const connection = new signalR.HubConnectionBuilder()
  .withUrl("/chatHub")
  .build();

connection.on("ReceiveMessage", (user, message) => {
  console.log(user + ": " + message);
});

connection.start();
```

------------------------------------------------------------------------

# 🔹 8. Types de communication

## Tous les clients

``` csharp
await Clients.All.SendAsync("ReceiveMessage", message);
```

## Client spécifique

``` csharp
await Clients.Client(connectionId).SendAsync("ReceiveMessage", message);
```

## Groupe

``` csharp
await Groups.AddToGroupAsync(Context.ConnectionId, "room1");
await Clients.Group("room1").SendAsync("ReceiveMessage", message);
```

# 🔹 10. Gestion des connexions

``` csharp
public override async Task OnConnectedAsync()
{
    Console.WriteLine(Context.ConnectionId);
    await base.OnConnectedAsync();
}

public override async Task OnDisconnectedAsync(Exception? ex)
{
    Console.WriteLine("Disconnected");
    await base.OnDisconnectedAsync(ex);
}
```
