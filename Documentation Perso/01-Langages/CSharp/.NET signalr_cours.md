# 📡 SignalR en .NET --- Cours complet

## 🔹 1. Définition

SignalR est une bibliothèque de communication temps réel pour ASP.NET
Core. Elle permet au serveur d'envoyer des données au client sans
requête (push).

## 🔹 2. Cas d'usage

-   Chat en temps réel
-   Notifications
-   Dashboards live
-   Jeux en ligne
-   IoT

## 🔹 3. Principe

SignalR utilise : - WebSockets - Server-Sent Events - Long Polling

## 🔹 4. Hub (exemple)

``` csharp
public class ChatHub : Hub
{
    public async Task SendMessage(string user, string message)
    {
        await Clients.All.SendAsync("ReceiveMessage", user, message);
    }
}
```

## 🔹 5. Configuration

``` csharp
builder.Services.AddSignalR();
app.MapHub<ChatHub>("/chatHub");
```

## 🔹 6. Client JS

``` javascript
const connection = new signalR.HubConnectionBuilder()
    .withUrl("/chatHub")
    .build();

connection.start();
```

## 🔹 7. Résumé

SignalR permet la communication temps réel entre serveur .NET et
clients.
